CRM Lite -- track leads and customer interactions (DOC-4 MVP item 3, DOC-5 CRM Lite Architecture).

Lead lifecycle: New Inquiry, Contacted, Quote Needed, Quote Sent, Follow Up, Booked, Lost, Archived.

Implemented directly in the platform database (D1). Borrows the XGD ticket and event model as inspiration rather than importing the implementation -- DOC-5 is explicit that a simpler product-native schema is preferred. The user never sees the ticket abstraction: they see Leads, Customers, Follow-ups, Conversations, Quotes, Invoices.

Explicitly out of scope: enterprise CRM functionality, complex marketing automation.

PII note per DOC-5: this is the main store of personal data, so export and deletion capabilities are required early, with audit events for significant actions.

State rationale: aspiration rather than concept -- lifecycle and architecture are specified, but no code exists and no date is set.
