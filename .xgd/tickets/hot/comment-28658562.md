#### You
I would like to design a simple image editing capability. The image editor will be a function alongside the image picker of the web editor. The selected image should be manipulable. Image editing tools should include cropping, colorizing, rotation, scaling. Note that we don't actually have to change the underlying image (I am open to suggestions on the right approach here) what we want to change is how the image is seen on the page. Note that however the image is displayed on the page it needs to appear the same way in the editor (obviously).
