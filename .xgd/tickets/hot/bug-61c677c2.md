## What happened
Two markdown documents uploaded as reference material (a letterhead and an invoice template) each begin with an HTML `<img>` tag for a logo. In `list_library`, their `title` is that literal tag, e.g. `<img src="images/logo.png" alt="…" width="180">`. The client sees the same thing on their Library tab. The descriptions were generated correctly.

## Expected
The title should be derived from the document's meaningful content, such as the first heading, the description's first sentence, or the filename. It should never be raw markup. At minimum, strip the tags (an `alt` value would be a reasonable fallback).

## Reproduce
Upload a `.md` file whose first line is an `<img …>` tag, then call `list_library`.
