**What happened:** A home page hero section (container, `composition: "overlay"`, `width: "bleed"`, layout stack) holds a `video` element (`sizing.height` fixed 720px, width fluid, objectFit cover) and an absolutely placed text container (`geometry.place: absolute`, `inset: content`, linear surfaceGradient from text@0.5 to text@0). With no change to the page data (the hero section was last written at change 150; draft now at 210, all later changes on other pages), the draft render at 1280px now shows the video at roughly 270px tall instead of 720px. The text container is now taller than the video and runs down over the next section, so the gradient reads as a dark band and the hero looks "halved and dark". The client noticed it without any edit to that page.

**Expected:** video at its stored fixed 720px height, text box inside it, as it rendered at changes 150–209.

**Reproduce:** draft screenshot of home at desktop; get_l1 home section hero path 0 shows `sizing.height {mode: fixed, px: 720}` unchanged.

**Suspect:** a renderer change in how `overlay` composition sizes its picture (e.g. now deriving height from the design's `imagery.aspects.hero` or from content) overriding an explicit fixed height, or a video intrinsic-size/poster change. Regression with no data change; also no layout warning was raised for it.
