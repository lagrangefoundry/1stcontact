## What the user sees

On xgd.dev, moving the mouse across a band that paints a grid texture lights the
grid lines **teal-petrol** inside a rough, roughly-circular region ~150–200px
across, centred on the cursor. The region is **stable while the pointer is
still** and its **edges deform as the pointer moves** — the "leaves appearing on
the digital trees" effect from sycamore.so.

It applies to **both** grid kinds on the page:
- the **hero**'s perspective grid, drawn by an SVG asset (`xgd-grid-hero.svg`);
- the flat hairline grid on `#problem` and `#close`, drawn by the L1 `pattern` axis.

It does **not** apply to the small `xgd-grid-mark.svg` logo marks (nav, footer) —
the axis is opt-in per node, so those simply do not carry it.

Nothing else changes: fills, grid colour, spacing and thickness are untouched, and
the accent never paints until a real pointer moves over the page.

## Why free-coded

One typed L1 axis plus a small renderer-owned script, following the shape REQ-100
(scroll reveal) already established. No design document needed.

## Design

**This is an L1 capability, not a behavior module.** It is pure presentation with
no user-facing behaviour and no instance data in JS — exactly REQ-100's case: a
typed value bag the renderer alone knows how to compile, plus one vetted script
identical for every site.

### 1. Schema — a node-level surface axis

`pointerAccent: { color, radiusPx, softnessPx?, roughness? }` (strict), added to
the shared surface-axes group, so any painting kind can carry it. `color` goes
through `l1Color`; the numbers are bounded. It is a **sibling of `pattern`**, not
nested inside it, because the texture it accents may be either the `pattern` axis
or a `backgroundImageUrl` — which is what including the hero requires.

The **blob count is a renderer constant, not an author dial** (see §4): the only
roughness the author names is `roughness` (0–1), which scales the lumpiness.

### 2. Renderer — the accent redraws the node's own texture in a second colour

An accented node gets an `::after` overlay (`inset: 0`, `pointer-events: none`,
`z-index: -1`, a selector no author can name), plus `isolation: isolate` on the
node itself so the negative-z overlay paints above the node's *own* background and
below its content, rather than escaping to an ancestor stacking context and
disappearing behind the band. (Verified safe: no node on the page uses
`blendMode`, which is the only thing `isolate` could otherwise perturb.)

Texture source, resolved in this order:
- **`pattern`** → the same pattern layers, recoloured; mask = the pointer region.
- **`backgroundImageUrl`** → paint = solid accent colour, mask = *the asset itself*
  ∩ the pointer region, at the identical `cover / center / no-repeat` geometry the
  base layer uses, so the teal strokes land exactly on the brown ones. The asset is
  strokes on transparent, so masking with its alpha recolours the grid **with no
  second asset and no colour baked into a file**. Its `stroke-opacity` (0.24) rides
  through the mask, so the accent inherits the texture's own weight.
- **neither** → nothing is emitted; there is no texture to accent.

Mask layers composite `intersect, add, add, …` (union of blobs, intersected with
the asset), emitted with both the standard and `-webkit-` longhands for
cross-browser reach.

### 3. Fail-visible, and round-trip-safe

The overlay rule is gated on a `data-l1-pointer` marker on `<html>` that the
script sets **only on the first real pointermove**, and its opacity reads a
custom property defaulting to 0. So:
- no JS, reduced motion, or a coarse/hoverless pointer (touch) → no marker, the
  rule never matches, the band paints exactly as it does today;
- the headless capture never moves a pointer → the captured page is unchanged and
  the L1 round-trip gate is unaffected.

### 4. Roughness and deformation, with no randomness

The mask is a union of N (renderer constant) radial blobs at **fixed angular
offsets** around the cursor with deterministically-varied radii — so the region is
lumpy rather than a neat circle, and that shape is *reproducible and stable at
rest*.

The script maintains N **lagging cursor trackers**, each easing toward the cursor
with its own constant. The angular offsets, radii and feather live in the CSS
(renderer-emitted from the axis); the script supplies only the trackers, so it
still carries **no instance data** — it does not know a radius or a blob count.
While the pointer moves the trackers spread and the boundary deforms; when it
stops they converge and the rough shape settles. The rAF loop runs only while the
trackers are still settling, and stops when idle.

Per-element it sets the tracker positions in the element's local coordinates plus
an on/off opacity property, so the accent follows the cursor from band to band and
fades on the ones it has left.

### 5. Site edit

`storage/sites/xgd/draft/pages/home.json` — `pointerAccent` on `#hero` (asset
branch), `#problem` and `#close` (pattern branch): teal-petrol `#2e86a3`, radius
~90px (~180px diameter). Final alpha/softness picked empirically by rendering,
since the brown grid sits at ~10% alpha and a full-strength teal is a large jump.

## Test plan

New UATs in `tests/req108-l1-pointer-accent.test.ts`, named
`test_UAT_FC_REQ-108_*`:

- a `pattern` + `pointerAccent` node renders an overlay drawing the same grid
  geometry in the accent colour, masked to a pointer-positioned region;
- a `backgroundImageUrl` + `pointerAccent` node masks the accent colour with the
  asset at the base layer's own geometry (the hero case), intersected with the
  region;
- the overlay is gated on the script-set marker and a zero-default opacity, so a
  document with the axis and no script renders identically to one without it;
- the script is emitted only when the axis is actually used, and carries no
  instance values;
- a node with the axis but no texture emits no overlay;
- the envelope rejects out-of-range / freeform / non-colour input on the new axis;
- a document that declares no `pointerAccent` renders exactly as before.

Regression scope: `tests/req103-l1-texture.test.ts`, `tests/req100-*`, plus the
L1 round-trip / render suites.
