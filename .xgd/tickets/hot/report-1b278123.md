UATs written and run. 11 of 13 pass; the two failures are a genuine code-vs-intent divergence, not test defects.

## What the tests do

`tests/reconciliation-platform-build-deploy-smoke.test.ts` — one UAT per AC, at three boundaries:

- **Real shell scripts against a fixture tree.** `bin/build` and `bin/deploy` resolve their repo root from their own location, so the unmodified scripts are copied into a temp tree that supplies the apps, hooks and environment. `pnpm`/`npx`(wrangler) are recording PATH shims — the external boundary, and the only way the composed command line and the hook→upload ordering become observable. Discovery claims additionally run `bin/build` against the **real** repo so the app set is the real one.
- **The real `1c` binary** for the preflight, with a `--import` hook making one shared component genuinely unresolvable. Nothing on disk changes.
- **`runSmoke` + the real `smoke.mjs` process** for the smoke checks, with `globalThis.fetch` replaced by a preload. The sandbox denies `listen()`, so a local HTTP server was not an option; this still exercises the real process, its exit status and its rendered summary.

## The two failures — one defect

`tools/generate/bin/1c.mjs:64-67` catches everything the CLI throws with `catch (err) { console.error(err.message); exitCode = 1 }`. For a `CommandError` that discards both halves of the failure contract:

- **`hint` is dropped**, so the remedy `cd ../lagrange-framework && bin/install --lang js --component all` is never printed — AC-1330 requires the refusal to name the install command.
- **`EXIT_CODES[code]` is flattened to 1**, so `1c preflight` exits 1 instead of 6, and `bin/build` — which propagates it — exits 1. AC-1330 requires "an environment-specific exit code (distinct from a general failure)"; AC-1331 requires the build to propagate it; and `bin/build`'s own header states *"Exit codes: 0 success; 6 environment (preflight); 1 anything else."*

The `assertInstall` gate path is unaffected because it routes through `fail()`, which does honour the contract — only errors thrown out of the command switch lose it. Everything else in both tests passes: the report lists both halves before refusing, distinguishes browser from server components, names the absent component and the import-map consequence; and the build discovers every Worker, bundles each with `--env production`, runs the preflight first, honours `--skip-preflight`, and refuses a tree with nothing to build.
