## Notes for the Editor

Nothing to repair. Three points worth carrying forward:

- **The suite is skip-gated and did not skip.** `describe.skipIf(!WEBUI_INSTALLED)` means this
  capability's entire evidence set evaporates silently wherever the shared `@lagrangefoundry/webui-*`
  store is absent (a fresh clone, CI, a linked worktree that cannot resolve it). It resolved and ran
  here — 9 passed, 0 skipped — but any future check at this level should re-run rather than read the
  green from a prior report, because a pass and a skip are not distinguishable in the matrix.
- **REQ-127's draft-key migration is correctly not an AC.** `builder-chat:<slug>` → `builder-chat:<sessionId>`
  is declared a one-time effect in both the intent and the story's Technical Context; AC-1067 tests the
  durable behaviour (per-conversation drafts) and not the migration. No coverage gap.
- **AC-1070 is deliberately outcome-shaped.** The generation token moved from `chat.js` to `app.js`
  when REQ-127 superseded REQ-122's mechanism. The test asserts the observable result and not the
  token, which is why it stays valid across that supersession — do not "strengthen" it into a
  mechanism assertion.
