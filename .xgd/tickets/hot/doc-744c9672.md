# Drawing and placing pictures: the Site consultant's reference

**Audience:** the Site consultant. Read this before you draw something with `draw_image`, or when you place one picture on the site in more than one framing. It holds the craft that `draw_image` and `place_on_site` used to carry in their descriptions ([[REQ-629]]).

## What drawing is for

- **A logo starts as a wordmark:** the business name well set — typeface, weight, spacing, maybe one simple rule or mark. The page's own typography does that better than any drawing, and keeps it crisp and editable.
- **An illustrated mark comes from image generation,** iterated with your client, not from paths you plot by hand.
- **Draw by hand for simple geometric marks, icons and dividers.** Don't offer drawn effects as a finishing touch ([[DOC-74]]).

## Drawing well

- **A run of styled text is ONE `<text>` with `<tspan>` children,** never several `<text>` elements placed by hand. The browser advances the pen from one run to the next; positioning runs separately means guessing at gaps that are wrong on every machine but one.
- **Name a real font.** `system-ui`, `-apple-system` and a bare `sans-serif` resolve to different faces on different platforms.
- **Give a node an `id`** when you mean to position it precisely: once the drawing is on the site, `measure_drawing` addresses it that way.
- **A redraw is a new item.** Drawing again makes another IMAGE-n; place the one you settle on.

## One picture, several framings

To use one upload cropped several ways (a montage, a contact sheet), place it once per framing with `place_on_site`, each with its own `as` name, then crop each placed file by its site name with `edit_image`. Each file's crop is its own. A crop made on the Library item reaches only the placed files that have none of their own.

Naming one of the item's existing files in `as` replaces that file. A name already taken on the site by something else is renamed rather than overwritten, so placing never replaces a different picture that is live; the answer says the name it actually got.
