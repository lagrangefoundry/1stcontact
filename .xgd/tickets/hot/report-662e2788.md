  reported **PASS with zero assertions executed**. This environment has therefore
  never had executing evidence for AC-815 — that is now visible in the run report
  as SKIPPED rather than hidden behind a green tick.

`background-image` (so AC-816's `backdrops.length === 1` is unaffected) and no
reuse of the `#ece6dd` / `#030717` colours the AC-816 guards test against.

It needs either a runner with Chromium installed, or an operator decision. This is
the same class of blocker as finding 3 (below), not a scoping failure.
