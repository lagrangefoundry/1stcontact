# Test Asset Catalogue

## Section 1: Test Architecture Overview

Mirrors the Test Architecture Summary (report_kind=test_architecture_summary).
Decisions recorded so far, from BUG-32:

- **Skip is evidence-scoped.** `WEBUI_INSTALLED` gating is legitimate for suites
  whose subject is component *behaviour* (they need a real mount). It is
  illegitimate for suites whose subject is component *identity or wiring* — the
  guard is presence-only and cannot distinguish "absent" from "renamed", so a
  conditional identity suite reports green on exactly the breakage it exists to
  catch. Identity/wiring UATs are positive and unconditional.
- **The artifact store is a precondition, never a mock.** The shared
  `@lagrangefoundry/webui-*` store is consumed through Node's ordinary upward
  resolution, populated out of band by `lagrange-framework bin/install`. Tests
  never alias, stub, or vendor it. In XGD branch worktrees it must be installed at
  the worktree parent so every worktree resolves it.
- **Assert against the generator, not a committed snapshot.** Import-map evidence
  is taken from `chromeHtml()` output. Committed chrome artifacts (`index.html`)
  are covered by the tree guard instead, so a stale snapshot cannot pass by being
  ignored.
- **Tree guards scan the git-tracked tree** with a small declared exclusion list,
  and are written so the guard file is not its own violation (split-and-join
  literal). Three hardcoded source roots miss committed artifacts.
- **Cross-surface coupling gets its own UAT.** Browser bare specifier ↔ generated
  import-map key agreement fails only at runtime in a browser; no build, type
  check, or unit test observes it.
