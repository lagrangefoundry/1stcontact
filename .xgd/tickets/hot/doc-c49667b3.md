# Test Asset Catalogue

## Section 1: Test Architecture Overview

Mirrors the Test Architecture Summary (report_kind=test_architecture_summary).
Decisions recorded so far, from BUG-32:

- **Skip is evidence-scoped.** `WEBUI_INSTALLED` gating is legitimate for suites
  whose subject is component *behaviour* (they need a real mount). It is
  illegitimate for suites whose subject is component *identity or wiring* — the
  guard is presence-only and cannot distinguish "absent" from "renamed", so a
  conditional identity suite reports green on exactly the breakage it exists to
  catch. Identity/wiring UATs are positive and unconditional.
- **The artifact store is a precondition, never a mock.** The shared
  `@lagrangefoundry/webui-*` store is populated out of band by
  `lagrange-framework bin/install`. Tests never stub, fake or vendor it — a
  stand-in would fork the upstream consumption route, which is most of the risk
  these suites cover. Failure to resolve it is an environment failure, read as
  such.
- **Vitest reaches it through aliases derived from the single resolution point.**
  Node's upward resolution finds the store from the main checkout but not from a
  linked `git worktree`, so nine of story-e674c60a's criteria (AC-959, 967–971,
  973, 974, 976) lost their evidence in every worktree while reporting green.
  `vitest.config.mts::webuiAliases()` corrects the *route*: targets come from
  `webuiPackageDir`/`webuiExports` (the same resolver production uses), keys are
  composed from `WEBUI_SCOPE` so a one-sided rename fails loudly in both
  directions, and with no install there is nothing to alias and the mount suites
  skip as before. This is a route correction, not the stand-in the bullet above
  forbids. The previously prescribed alternative — installing at the worktree
  parent — was not taken: its failure mode is the silent green, not a loud one.
- **Assert against the generator, not a committed snapshot.** Import-map evidence
  is taken from `chromeHtml()` output. Committed chrome artifacts (`index.html`)
  are covered by the tree guard instead, so a stale snapshot cannot pass by being
  ignored.
- **Tree guards scan the git-tracked tree** with a small declared exclusion list,
  and are written so the guard file is not its own violation (split-and-join
  literal). Three hardcoded source roots miss committed artifacts.
- **Cross-surface coupling gets its own UAT.** Browser bare specifier ↔ generated
  import-map key agreement fails only at runtime in a browser; no build, type
  check, or unit test observes it.
- **"No exempt case" is probed structurally, not by representatives.** A UAT for a
  criterion claiming every response/route/tree reads the declaration out of the
  production source and checks coverage both ways — declared-but-unprobed and
  probed-but-undeclared. A hand-maintained sample list is what let AC-977's JSON
  responses ship cacheable while the criterion reported green.
