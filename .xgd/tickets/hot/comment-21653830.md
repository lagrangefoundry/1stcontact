## What shipped

**The window** — resolved from the configured model by the framework, not declared beside it. A `context_window` written next to `model` in `backends.json` would outlive the next model change and hand a session the denominator of a model it isn't running; the framework refuses that key in its own defaults for exactly that reason. What was actually missing was the alarm, so `configureProjectBackends` now refuses to start if any entry resolves no window — the silent-degradation path on a model rename.

**The gauge** — the framework's own `session.budget` provider, in the framework's own position past the product tier's cache boundary, so it rides the per-turn tail and can't invalidate the cached prefix. Rebound to a figure the host keeps durably (`occupancy_tokens` on the `chat` ticket), because this Worker rebuilds the manager per request and upstream's in-memory copy reads zero on every turn.

**The guard** — refuses on measured occupancy at both moments: pre-turn from the stored figure, and in-turn by stopping the adapter's tool loop *between* two requests, so the oversized one is never built. The turn ends `aborted` naming `context_budget`, the client is told why in the session's place, and the spend still reaches the meter.

**The work log** — `read_work_log` on the ledger surface (index, or one turn in full), which is also the reader that finally makes the framework's tool-transcript pointer a true claim rather than a tool the session hasn't got.
