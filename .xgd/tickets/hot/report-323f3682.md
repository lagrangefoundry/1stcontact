  `wrote N file(s):` followed by one indented line per written path, instead of
  a bare count.

  not a double-prefix: `readPages` (`colors.ts:154-160`) builds `rel` from

  now parses the filenames back out of `run.stdout` into `reported`, asserts

  pre/post hash comparison from `reported` rather than from a filesystem-derived
  list. This is exactly what AC-941's Verification demands: "every file **named
  in the report** differs from its pre-retrofit content while no other file
  does."

## Notes for the Editor

No action required. Retained observations for future drift checks:

- *Fixture realism is load-bearing.* The census UATs assert against the real
  stored `xgd` site, which already carries a palette; the alpha family they pin
  (`#2e86a3` at α 1.00 / 0.65 / 0.33) exists as three `primary` references
  carrying `alpha` 255/166/85, not as 8-digit literals. This is what makes
  AC-947's "references are measured as the colours they resolve to" a live claim
  rather than a restatement. `harbor-cafe` genuinely carries zero colour
  literals, so AC-939's zero-census branch is real. Any future edit to
  `storage/sites/xgd` or `storage/sites/harbor-cafe` should expect to touch
  these UATs — that coupling is intentional, but it is a coupling.
- *AC-871's browser gate is sanctioned.* `it.runIf(browserOk)`
  (`reconciliation-scaffold-starter-l1.test.ts:48`) is the only conditional
  execution anywhere in the capability's four test files; the AC body explicitly
  admits it, and Playwright's chromium is installed in this environment, so the
  test does run here. In a browser-less environment this AC would have no
  executing evidence.
- *AC-870 and AC-874 share two incidental assertions* (`display: flex`,
  `align-items: center`, both document-wide `toContain` on the rendered HTML).
  Not an exclusivity violation: AC-870's core is the placeholder painting on the
  seeded background read back off disk, AC-874's is the absence of any
  `geometry` track and of `position: absolute`. Different scenarios, different
  cores.
- *AC-1018 asserts only `typeof entry.kind === 'string'`.* Deliberate and
  correct: kind derivation is AC-1021's subject, and duplicating it here would
  be the redundancy this check screens for.
