## 1. Give the API token Containers permission (about 3 min)

1. Open https://dash.cloudflare.com/profile/api-tokens.
2. Find the token whose value is in your shell's `CLOUDFLARE_API_TOKEN`. It's the one used for D1, Workers Logs and deploys. **Edit** it; don't create a new one, so nothing else changes.
3. Under **Permissions**, add **Account → Containers → Edit**. If the list also offers **Account → Cloudchamber → Edit** (the older name for the same registry and scheduler), add that too.
4. Leave Account Resources as they are (your account), then **Continue to summary → Update token**. The token value does not change.
5. Check it, from the repo:
   ```
   cd apps/control-app && npx wrangler containers list
   ```
   ✅ **Pass:** an empty list or a table, with no "Authentication error".

## 2. Run Docker Desktop and keep it running (about 5 min)

1. Open **Docker Desktop** from Applications and let it finish starting (whale icon steady).
2. **Settings → General:**
   - tick **Start Docker Desktop when you sign in to your computer**;
   - tick **Use Rosetta for x86_64/amd64 emulation on Apple Silicon** (builds amd64 images much faster).
   Then **Apply & restart**.
3. **Settings → Resources:** set memory to at least **8 GB**. Dev will run a 4 GiB agent container beside the rest. Apply.
4. Check it:
   ```
   docker info --format '{{.ServerVersion}} {{.OSType}}'
   docker run --rm --platform linux/amd64 node:22-slim node -e "console.log(process.arch)"
   ```
   ✅ **Pass:** a version followed by `linux`, then `x64`.

## 3. Let Claude sessions reach Docker

The REQ-646 session has to build and run the image, and its sandbox may block the Docker socket (`~/.docker/run/docker.sock`).
- After step 2, ask the EPIC-32 session to run `docker info`.
- If it is refused, add the socket to the sandbox allowances for this project (your settings; Claude can't change them). Otherwise the image builds have to be run by you.

## 4. Set a spending notification (optional, about 2 min)

Dashboard → **Manage Account → Billing → Notifications** (or **Notifications → Add → Usage-based billing**):
- add a usage alert for **Containers** at, say, **$20/month**;
- expected spend is about $0.02 per turn, beyond the included 25 GiB-hours a month.

This catches a container left awake by a bug, the one way containers get expensive.

## 5. Not needed

- No Containers sign-up or waitlist: it is available on Workers Paid, which the account has.
- No new secrets: the container receives the model keys from the Worker's existing secrets.
- No change to the wrangler login.

`npx wrangler containers list` passes, both `docker` commands pass, and a Claude session can run `docker info` (or you've decided to run the builds yourself). Tell the EPIC-32 session, which will unblock REQ-646.
