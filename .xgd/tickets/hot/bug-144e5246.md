Filed by `repro-console:repro-www-bluelotusintegralhealing-com#1`.

**Class:** `instrument-blind`. `1c l1-gate` judges the served document with its own layout model (`tools/generate/src/l1/probes.ts`, `layoutInFlow` and friends), not with a browser. On this reproduction that model disagrees with Chromium on the same served HTML by 84px in one place and 575.75px in another. It reports `sampleFidelity: pass, maxDelta 0.009` for a page whose whole surface layer is 84px off in the browser.

**Stored reference:** `storage/references/www.bluelotusintegralhealing.com/index`. Reproduction `repro-www-bluelotusintegralhealing-com`, evidence in `storage/tmp/repro-console/repro-www-bluelotusintegralhealing-com/iteration-1/` (`$ITER`). One bundle only.

## 1. The model does not implement margin collapsing, so it cannot see the defect REQ-371 issue 2 describes

- Served CSS: `.l1-0 { position: relative }` (the root) and its first in-flow child `.l1-6 { margin-top: 84px }` at ≥1024. In a browser that margin collapses out of the root, so the root and every absolutely-placed child move down 84px.
- Chromium at 1280×800 on `$ITER/site/index.html` (`--single-process`): `.l1-0` y **84**, `#backdrop-0` y **84** (L1 y 0), `#backdrop-1` y **1050** (L1 966), `scrollHeight` **3030** (reference 2946). `$ITER/diff/actual-manifest.json` agrees: elements at y 84 / 1050 / 1562 / 2077 / 2637 = L1 + 84 each.
- The model: `bin/1c l1-gate repro-www-bluelotusintegralhealing-com --ref storage/references/www.bluelotusintegralhealing.com/index --sandbox --json` returns `"sampleFidelity": {"pass": true, "tolerancePx": 2, "maxDelta": 0.009374999999977263, "residuals": []}`.
- `probes.ts:941-948` reasons explicitly about containing blocks and origins, but nothing in `tools/generate/src` models margin collapse (`grep -rni collaps tools/generate/src/l1/probes.ts` finds only unrelated "collapse to 0 height" uses). `fold.ts:3025-3028` knows the hazard exists.

**Wrong:** sampleFidelity passes at 0.009px on a page whose pinned layer is +84px in the browser. **Right:** either the model collapses a geometry-less block's first in-flow child's top margin through it (when the block has no padding/border/BFC), or sampleFidelity is measured in a browser. Then this page reports an 84px residual on `backdrop-0..2`, `box-0..1` until the renderer fix lands, and 0 after.

## 2. The model places the `0.6` subtree 575.75px lower than Chromium does, so every `escape` magnitude in the structural-failure verdict is the model's, not the page's

- `gate.json` → `layout.findings` at 1280×768: `'About Me' … 212px below its bottom edge` with the model's box for `0.6.0.0.0` at **y 1628.75**. The card text `0.6.1.0.0` is at **y 2515.95** and quoted as "1062px below" `backdrop-2`.
- Chromium, same served HTML, same width: About Me (`.l1-18`) box at **y 1053** (`actual-manifest.json` element 8), and `#card-0` at **y 1482.5**. Difference: 1628.75 − 1053 = **575.75px** at the first, and similar below.
- Working back from L1 leads (`section-band-1` lead 0, About Me lead 122): the model ends the hero at 1506.75 where Chromium ends it at 931. Its hero content (before the 256px bottom padding) ends at 1250.75 vs Chromium's 675 (the CTA row: `.l1-11` y 654 h 21). The mechanism inside the model is **cannot-tell from what I have**. The CTA row is a `container` with `responsiveLayout` stack→row at 1024, with flow children carrying x leads 233.98 / 12.97 / 11.01 / 11.99; a model that laid that row out as a stack, or measured the pills' text height differently, would produce an error of this order. **To tell, I would need** the model's per-node boxes for `0.5.3.*` at 1280 (a `--json` dump of the evaluated layout, which `l1-gate` does not currently emit) next to Chromium's.
- Consequence: the 36 `escape` findings are real in kind (in Chromium card-0's text does start 79.5px above `backdrop-2`'s rendered top at 1280), but every magnitude the verdict prints (212 / 643 / 1062 / 1180 / 1673px) is the model's, not what the browser draws.

**Wrong:** `l1-gate` escape magnitudes 575.75px away from the browser on the same document. **Right:** the model's box for `0.6.0.0.0` at 1280 within the 2px `tolerancePx` of Chromium's (1053 now; 1088 once REQ-371 issue 3 restores the pill height). Add a self-check that compares the model with a single browser layout at one ladder width and fails loudly when they diverge, so the gate cannot report on a document it has mis-laid.
