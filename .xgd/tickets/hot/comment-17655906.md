## What I built

**The rule:** switching View↔Edit now shows the same page in the same state — same page path, same scroll offset, same panels open.

**Three pieces:**

1. **`packages/framework/src/l1/render.ts`** — the edit render now emits the modal apparatus in full (covering shell, `data-l1-dialog` id, `role="dialog"`, both halves of the overlay stylesheet). It used to drop all of it along with the script, which left nothing in the edit document that a channel switch could *tell* anything. Emitting it costs that channel nothing: every overlay rule is gated on a marker only a script — or the builder — sets, so an edit render nobody has told anything still lays the panel out in flow and settled, exactly as REQ-116 wants. The one line that keeps it inert is now the script gate, and it's the only one that has to be.

2. **`packages/framework/src/l1/page-state.ts`** (new, plus `dialog.ts` for the shared attribute vocabulary) — reads a page's state off a window and puts a window into one. The two channels differ deliberately: **Edit is told** (markers set directly — no script, none wanted), **View is driven** (the opener is *activated*, so the page's own script does the opening and focus, the scroll lock and `aria-expanded` are all true afterwards). It's the same handle REQ-216 needs.

3. **The builder** — `carry.js` holds the state across the swap that destroys the document; `panel.js` announces when a document is going and when one has arrived; `previewUrl` gained the path within the channel. Edit also gains a **panel selector**, because a modal reproduced there covers the page and its own Close is inert — it's the escape hatch and the way to edit copy inside a modal you never opened in View.

**Deliberate scope:** L1 dialogs only. A behaviour module's panel (`account-chrome`'s sign-in dialog) keeps its settled state — reaching into one would mean this module knowing what an `account-chrome` is, which is what the carousel's own rule forbids. So the ticket's open question is answered: `data-fc-edit` does *not* grow to carry which state; it stays the fallback for "nobody said".

**Supersession, stated explicitly on the ticket:** REQ-212 §5.7 / AC-12's "no shell, no role in edit" becomes "the shell and the role, always". I updated that UAT rather than leaving reconcile to discover the conflict.
