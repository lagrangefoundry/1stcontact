# Framework Reproduction Module Treatments

Per-module authoring treatments that faithful site reproduction forced onto the
`services-grid`, `contact-form`, and `footer` modules. These are targeted
authoring dials/content fields (not new modules) that let a site author render
translucent "frosted" card bands, compact placeholder-labelled / inline
contact forms, and footers whose copyright and link/body colours depart from
the surface default.

Scope: the module treatment surfaces themselves. The underlying absolute-or-
overlay colour resolution these treatments consume belongs to the Absolute-or-
Overlay Value System capability (CAP-67); this capability covers the
module-level authored behaviour a site author observes in the rendered page.
