The content-width dial system: how an author caps a section's content column
(and a grouped row's width) to a chosen measure. Provides a coherent named
width scale for the common case plus a literal escape hatch for off-scale
widths, applied uniformly across the width-bearing modules (hero, text-block,
services-grid, and grouped rows).
