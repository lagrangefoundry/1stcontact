# Framework: Art-Direction Language

Structured, framework-owned primitives that let a site's sections be art-directed
beyond the base module catalog — closing the biggest reproduction gaps from the
capture design (text over background imagery, free-positioned layered composition,
and entrance/scroll/hover motion).

Each primitive is expressed as structured data on a module instance (validated by
the site schema) and turned into scoped, framework-computed CSS/markup at render
time — never raw instance-supplied CSS. This capability hosts the section
background, layer/z-compositing, and motion primitives.
