The platform-level knowledge base -- knowledge that belongs to the system rather than to any one site.

This is the Reference Document library DOC-10 commits to: material the AI consults on demand, shared across every site. Prior art already exists in the XGD ticket store, where doc tickets carry a system_kb flag (DOC-10 and DOC-13 both set it), so the notion of system-level knowledge is established and can be borrowed.

Likely contents: design knowledge and the design rubric (DOC-16), the Design Lessons Log (DOC-17), the reference corpus (DOC-15), framework and module documentation.

Distinguished from the project KB, which is per-site. The boundary between the two is one of the open design questions.
