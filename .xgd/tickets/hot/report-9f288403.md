## Grounding note — correction to the report's suggested wording

The report's suggested edit proposed the AC assert `--out` "writes the N-way table (and, with `--classify`, the classification)". The reconciled implementation (this is a `free_and_reconciled` capability, so code is authoritative) contradicts the parenthetical:

- `--out` persists *in addition to* stdout, not instead of it.
- This matches the STORY-78 body ("optional `--out <file>` to persist **the table**").

AC-721 therefore asserts the true behavior: `--out` persists the raw N-way table regardless of `--classify`, and stdout still emits per the classify/json/default flags. Recorded as comment-efae8ed5 on report-77eb6a65.
