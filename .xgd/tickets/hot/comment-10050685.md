## What I built

**The rule:** bytes this system mirrored from a captured page may not enter a site's assets.

I took the ticket's **narrow framing** rather than the broad one. Minting a `material` ticket per seeded asset is REQ-228's shape decision (it's the one that has to cover fonts, stylesheets and build output), and more importantly a ticket for a capture-mirrored photograph would *record* the infringement rather than prevent it — there is no `rights` block that makes a third party's picture publishable on a client's domain, so the only honest entry is a refusal.

**Identity is the sha256 of the bytes.** The copy into `storage/sites/<slug>/draft/assets/` destroys every other link back to the capture — the member arrives under its own basename in a directory that records nothing — so a path test has no path left to read and a name test is defeated by a rename. The content hash is the only evidence the copy cannot erase.

**Enforced at both halves of the one door**, because each holds different evidence:
- `1c push` against the operator's own `storage/references/` tree — **this is the half that catches the reported instance**, since the gigabytealchemy capture was taken on a laptop and never reached R2, so a Worker-only check would have found nothing to match.
- `POST /api/import` against the tenant's R2 bundles — the Worker is the writer, and a rule only the client applies is not a rule.

One predicate (`assertNotCaptureMirrored`, over the `ReferenceStore` port), two adapters. The import route answers **403**, kept distinct from BUG-51's 409 (a question `--force` answers; this is a rule with no answer). The gate runs before `createDraft`, so a refusal leaves nothing behind, not even an empty draft.

**Proved against the real corpus**, through the production `readSitePayload`:
```

OK      1stcontact: 0 asset(s)
REFUSED gigabytealchemy: '8vIJ7ww63mVu7gt79mT7PkRXMw.woff2' is byte-for-byte a
        subresource we mirrored from a captured page (gigabytealchemy.ai/index/…)
```

11 UATs (6 node, 5 workerd, real D1/R2, nothing stubbed). I verified RED by neutering the predicate: 4 of 6 and 2 of 5 fail without it.

**Test sweep:** 3699 passed, 3 failed — `bug32-webui-scope-rebrand` and `BUG-67 backend_settings` fail identically on unmodified `xgd-working`, and `reconciliation-colour-census` is a parallel-run flake (green in isolation on both trees).
