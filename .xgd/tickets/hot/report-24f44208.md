# Fix Plan — Iteration 17

## Hypothesis
AC-688 shows as orphaned only because its one test, `test_UAT_AC688_no_layout_divergence_across_three_engines`, is skipped. The skip is the clean skip the AC allows: this machine's Playwright cache does not have the WebKit 2311 and Firefox 1532 builds that the pinned Playwright 1.61.1 needs. The coverage gate counts that allowed skip as "no passing test". That is the XGD tooling defect BUG-1696, also filed earlier as BUG-1695. No change in the repo can clear it.

## Analysis
- **Quality report:** REPORT-11780 (report-5b647c91) has 54 passed, 0 failed, lint and build clean. The only failure is the matrix check that flags AC-688 as orphaned.
- **What changed since iteration 16:** only `.xgd/_changes/*` and the quality report. No source, test, AC or environment change.
- **Environment, re-checked in this iteration:** `~/Library/Caches/ms-playwright` still holds `firefox-1538` and `webkit-2336` and no `firefox-1532` or `webkit-2311`. So `engineAvailable('webkit')` and `engineAvailable('firefox')` (`tools/generate/src/cli/capture/playwright-driver.ts`) still return false, and `it.runIf(allEnginesReady)` (`tests/reconciliation-l1-substrate.test.ts:530-534`) still skips.
- **History:**
  - Every builder assessment from iteration 1 to 16 makes the same diagnosis.
  - Iteration 2's builder tried the install, and the sandbox refused it with `EPERM mkdir ~/Library/Caches/ms-playwright/__dirlock` (REPORT-11732).
  - Iterations 14 to 16 left AC-688 out under the BUG-1067 tooling-defect rule. Iteration 16's builder reported `no_change` (REPORT-11777).
- **Hypothesis count:** the "stale browser cache plus BUG-1696" diagnosis has been confirmed more than three times. The anti-repetition rule's escape (b) applies: the hypothesis is correct, and the blocker is the XGD coverage tooling plus a sandbox-refused operator action, not a mode rule this plan can lift.
- **Other approaches considered and rejected:**
  - Bump or downgrade Playwright to match the cache. Rejected: the reference pins `"playwright": "^1.61.1"` at `tools/generate/package.json:21`.
  - Point `PLAYWRIGHT_BROWSERS_PATH` at a writable directory. Rejected: the gate does not inherit the builder's environment, so it needs a frozen test or driver change. It also needs a network download, and the browsers would end up inside the worktree.
  - Retire AC-688. Rejected: the behaviour is real and the reference has it.
  - Add a cheap test that passes without browsers. Rejected: it would be false evidence for a cross-engine claim.
- **Blocked-by request:** none is attached to this iteration, so there is nothing to rule on.
