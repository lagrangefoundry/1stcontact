# values-diff: the reference's page background is inferred from the tallest band, so the one thing a bundle records seven times is never compared

Filed by `repro-console:repro-joyfulculinarycreations-com#4`, iteration 4 of the reproduction of
https://joyfulculinarycreations.com.

`defect_class`: **`instrument-blind`**.

This is the ruler half of the gap ticket filed alongside it (issue 1 there — the fold takes the page
canvas from the tallest band). The engine half is that the reproduction paints the wrong canvas. This
half is that **the comparator cannot tell**, because it derives the *reference's* canvas by the same
broken method and then compares the wrong value against itself.

## What happens

`tools/generate/src/cli/capture/value-axes.ts:849-856`:

```ts
{
  axis: 'bodyBackground',
  role: 'carried',
  note: 'BUG-27 — the page\'s base fill: what shows through wherever no band paints. Read off `<body>` on the reproduction side; inferred from the widest band on the bundle side, because that is the only place a bundle records it. …',
  reference: (capture) => pageBaseOf(capture.sections),
  reproduction: (signals) => signals.bodyBackground,
}
```

and `pageBaseOf` (`value-axes.ts:821-832`) is the largest-area section carrying a background colour:

```ts
for (const s of sections) {
  const area = (s.box?.width ?? 0) * (s.box?.height ?? 0)
  if (area > bestArea && s.background.color) { bestArea = area; best = s.background.color }
}
```

**The note's premise is false.** The bundle records `bodyBackground` directly, at every projection, in
`multistate.json` — written by the extractor at `tools/generate/src/cli/capture/extract.ts:3068`
(`bodyBackground: bodyBg`). It is `capture.json` that carries no such key; `multistate.json` sits
beside it in the same bundle and the differ already reads it.

## The evidence

Bundle: `/Users/martin/lagrangefoundry/1stcontact/storage/references/joyfulculinarycreations.com/index`
(`capturedAt` 2026-09-29T19:46:13.536Z, `captureSchema` 8).

```

print(sorted({p['manifest']['bodyBackground'] for p in m['projections']}))"
```

→ `['#ffffff']` — all seven projections agree, and the page's mirrored stylesheet has it in one line
(`assets/reset.css`: `body{background-color:#fff;…}`).

What the comparator computed instead, from
`/Users/martin/lagrangefoundry/1stcontact/storage/tmp/repro-console/repro-joyfulculinarycreations-com/iteration-4/diff/`:

```
python3 -c "import json;
print('expected', json.load(open('expected-manifest.json'))['bodyBackground']);
print('actual  ', json.load(open('actual-manifest.json'))['bodyBackground'])"
```

```
expected #7a7a7a
actual   #7a7a7a
```

`pageBaseOf` picked `capture.json` `sections[3]` — `{x:0, y:1335.97, w:1280, h:1331.546875}`, area
1,704,380, `background.color "#7a7a7a"` — over `sections[6]` (`h 525.015625`, `#ffffff`) and
`sections[1]` (`h 800`, `#000000`). It is the largest band; it is not the canvas.

## What it costs

The page has three strips where no band paints and the canvas shows through — `capture.json`
`sections[5]` and `sections[7]`, both `{"kind": "none"}` (the `margin-top:15px; margin-bottom:15px` of
`.elementor-element-e1fc299`), and the 1px gap between `sections[8]` and `sections[9]`:

| document y | reference pixel at x=640 | reproduction |
|---|---|---|
| 2934.52–2949.52 | `(255, 255, 255)` | `(122, 122, 122)` |
| 3474.53–3489.53 | `(255, 255, 255)` | `(122, 122, 122)` |
| 4439.63–4440.63 | `(255, 255, 255)` | `(122, 122, 122)` |

Mean **exactly 133.00/255** over each strip (`|255 − 122|`), full width, which is the highest mean
anywhere on this page. **22.34% of the page's total absolute pixel-difference mass**, and **27.63% of
the ranked region score** (`regions.json` region #3 `score 10004.23` and region #4 `score 8645`, of
67497.33).

`values-diff.json` reports **zero deltas** for it. `bodyBackground` is `role: 'carried'`, so it is not
compared at all — but even if it were, both sides now read `#7a7a7a` and the comparison would pass.
The two highest-`meanDiff` regions on the page (#4 at 108.06, #3 at 62.53) name a `section` record on
both sides and no run on either, which is the ranker correctly saying "the paint behind everything is
wrong" — and nothing in `values-diff` can follow it.

## The proposed change

1. `reference: (capture) => …` should read the bundle's recorded value —
   `multistate.projections[].manifest.bodyBackground`, which the differ already loads — and fall back
   to `pageBaseOf(capture.sections)` only when no projection recorded one. Correct the note while you
   are there: the claim "that is the only place a bundle records it" is what made this invisible.
2. Consider promoting the axis from `role: 'carried'` to `role: 'compared'`. It is a single colour per
   document, it is recorded on both sides, and on this page it is worth more pixels than any value the
   table does compare. As a compared axis it would have produced one delta instead of 22% of the page's
   disagreement in silence. (This will **raise** the delta count by one on this bundle, which per
   [[REQ-277]] is the instrument sharpening, not a regression.)
3. The capture should also write `bodyBackground` into `capture.json` so the primary record is not the
   one place it is missing — that half is in the gap ticket's issue 1 and is capture-side, so it needs a
   re-capture. Item 1 here needs neither a re-capture nor a refold.
