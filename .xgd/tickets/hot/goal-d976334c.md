The chat-based website builder -- the primary user interface for the platform (DOC-4 MVP item 2). Users interact by conversation: create a catering website, move testimonials higher, add a wedding package, make the site feel more premium. Preferred experience is a chat window beside a live preview, with the site built progressively while the user watches. Onboarding is part website creation, part business consultation.

Build-order note (DOC-16 section 4): we do NOT build the builder first. The order is framework primitives, then the two flagship sites, then the builder -- once the framework and the design intelligence are proven. The flagship sites are the R and D vehicle that generates the design intelligence.

Evidence: builder shell, multi-mode display panel and toolbar landed under REQ-115 (commit e07c27bb1), the most recent feature commit. Page editor design is DOC-28; builder UI principles are DOC-8. Source at apps/control-app/src/builder.

Dependency note: this consumes the website framework, which is a separate project with its own goal map. A cross-project depends_on will be wired once those goals exist.
