#### Claude
Yes, whenever you want webhooks in dev. `stripe listen` is the only path from Stripe to your machine. While it's stopped, events still happen in the sandbox but nothing reaches `127.0.0.1`. In practice:

- **Keep it running in its own terminal tab while you test payments.** In that state a test Checkout marks the invoice paid, and Connect sends `account.updated`.
- **When it's stopped, nothing breaks.** Invoices just won't change to paid, because only the webhook confirms a payment. The success redirect never does.
- **Events from while it was off aren't sent later.** If you missed one, replay it after restarting with `stripe events resend evt_…`, or simply repeat the test.
- **You don't need to set the secret again.** The `whsec_` stays the same between restarts on this machine, so set it and deploy once.

You only need it running while you're testing payments or Connect locally. The rest of dev works without it.
