## Notes for the Editor

**Nothing to do at this level.** Zero violations, zero warnings, zero needs_review. Every
finding above is an `info` ledger entry whose action is "none".

**What closed the five-pass loop, for the record.** The first four fixes each replaced an
over-broad claim with a narrower one drawn from the *previous report's* account of provenance,
and each narrower one was still on the wrong side of the boundary. Fix 5 read the
disambiguating commit itself (`git show 2b902ead0^:tools/generate/src/cli/preview.ts`) and
deleted. The lesson worth carrying: when a boundary dispute turns on *when* a mechanism
arrived, the pre-change commit settles it and `origin/main` cannot, because a moved line reads
as a new one.

**For the uat cycle.**
- Before authoring any UAT for AC-1327, check CAP-85's AC-1033 (`acceptance_criterion-ae33f0ab`,
  STORY-99 `story-e674c60a`, `capability-a994b8f3`) first — it already carries
  `uat_coverage: pass` for the freshness experiment, and AC-1327's deletion exists precisely so
  a second proof of it is not authored here. AC-1327's three bullets need only the preview
  route driven against a filesystem-free store.
- AC-1353's and AC-1329's checks are **structural by intent** (an assertion over what modules
  import; an assertion over the two configs' inclusion rules), not structural for want of a
  behavioural route. AC-1353's own text explains why a behavioural run cannot substitute: under
  `nodejs_compat` the Workers runtime resolves a filesystem import and hands back a per-isolate
  filesystem, so a command that reached for a file would pass every behavioural assertion and
  still lose the operator's work. Do not fail these as non-substantive.
- AC-1324 and AC-1325 are the pair a single parameterized suite over both adapters can satisfy;
  that is by design (finding 3), not a duplicate to be collapsed.

**Carried forward unchanged.** The rationale comment in `vitest.workers.config.mts` still
states REQ-141's retracted supply-chain diagnosis for the test-pool pin. No AC encodes the pin
or its rationale, which is correct and deliberate per STORY-118's "Known divergence" paragraph
— that paragraph must not be removed, or a later reader will re-derive the retracted theory
from the stale comment.
