A behavior module letting a built site expose an authenticated area to its own
visitors — the site owner's customers logging in to see their own records.

Distinct from the app-level **User portal** goal, which is 1stcontact's own
account surface for *our* customers. This one is a module the editor can place
on a customer's site.

First consumer: XGD website Phase 2 "User portal".
