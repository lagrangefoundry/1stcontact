## Notes for the Editor

- This capability is a clean single-story feature whose intent is a well-scoped
  slice (REQ-86) of a large multi-capability bundle (BUNDLE-7). The main risk in
  a bundle-linked story is over-claiming sibling REQ behaviour; STORY-86 does the
  opposite — it explicitly names CAP-70 (renderer/validator) and CAP-71 (fold) as
  out of scope, so there is no coverage bleed.
- The "reproduce a real site end-to-end" phrasing in REQ-86's title/goal is the
  one place a future reader might expect a live-site run in this capability. It is
  deliberately not here; the gate is the acceptance *decision procedure*, and its
  Delivered evidence is analytic UATs (including a non-vacuous discriminator that
  fails on the pinned base and passes after demand-driven promotion). If intent
  later adds an actual real-site reproduction run as durable behaviour, that would
  be a new AC/UAT under this story (or a sibling story), not a rewrite of the
  current body.
