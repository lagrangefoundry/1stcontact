# Example businesses

Made-up small businesses for role-playing the site builder. The operator
plays the owner. Each folder has a fact sheet with paste-ready chat
fragments (`README.md`), a services/price list, a backstory, mock reviews,
a blank invoice, a letterhead and a comparison with real local competitors.

| Folder | Business | Where | Speciality |
|---|---|---|---|
| `charlies-plumbing/` | Charlie's Plumbing | Santa Cruz, CA | Emergency plumbing; loves kitchen and bathroom installs |
| `bobs-salon/` | Bob's Salon | South Boston, MA | Long hair for men and women; nails and facials |
| `ariels-arcwelding/` | Ariel's Arc Welding | Oakland, CA (Jingletown) | Welding, fabrication and repair for boats, cars, buildings and aviation; scrap-metal sculpture; kids' classes |

Anything not marked as canon in a business's README is invented. It only
counts once you've said it in the room.
